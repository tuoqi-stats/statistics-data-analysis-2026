# 第 6 章 综合练习

前面 5 个主题的文件都是「一个知识点一个文件」，而这个目录里的练习**故意把多个知识点揉在一道题里**——这才是真实写代码的样子。

这里没有新语法，只有**新组合**。做完这一章，你就相当于把前 5 章串成了一条线。

---

## 怎么用这个目录

1. 打开 `01_综合练习_基础.py`，**每一题都有题目说明和代码框架**；
2. 在 `# TODO` 的位置把代码补全，运行你的文件，看输出对不对；
3. 做完**一题**就可以打开答案文件对照一题（答案里有 `第 X 题` 分隔标题，题号严格对应）；
4. 基础 8 题全部做对后，再挑战进阶 6 题；
5. 最后读两个迷你项目——它们是「把前面所有知识组装成一个小软件」的样子，**强烈建议自己改数据、改规则再跑一遍**。

## 自查清单（做完后逐条打勾）

### 基础部分
- [ ] 我能看懂 `float("1.75")` 为什么必须做类型转换
- [ ] 我能独立写出闰年判断，并解释为什么 `or` 和 `and` 的优先级要注意
- [ ] 我能说出 `12 & 10` 等于几，以及 `bin()` 输出的 `0b` 是什么意思
- [ ] 我知道 `range(1, 101)` 里为什么写 101 而不是 100
- [ ] 我能解释 `n // 10` 和 `n % 10` 分别做了什么
- [ ] 我知道 `max()` 返回的是值，`index()` 才能拿到位置
- [ ] 我会给函数写默认参数，并知道 `return` 和 `print` 的区别
- [ ] 我能读懂一行嵌套的条件表达式，并能改成 `if / elif / else`

### 进阶部分

- [ ] 我能用 `sorted(..., key=lambda x: ...)` 按自定义规则排序

### 项目部分
- [ ] 我能说出成绩管理项目里每个函数负责什么
- [ ] 我能把项目里的硬编码数据换成我自己的数据并跑通

## 温馨提示

- 这些练习**不使用 `input()`**，所有数据都写在代码里，运行即可看到结果，**不会有"程序卡住等你输入"的情况**；
- 每个文件都能在 **1 秒内**跑完。如果某个文件跑起来没动静，说明可能不小心写出了死循环，检查一下 `while` 的条件在循环体里有没有变化；
- 如果某题实在写不出来，先看答案里的**思路注释**，理解后**关掉答案自己重写一遍**，不要直接抄；
- 报错是好事，**报错信息会准确告诉你第几行出了什么问题**，学会读它是重要技能。
