## 一、先弄明白：什么是表达式？

一句话类比：

- **表达式（expression）** 像「一道算术题」—— 它**有值**，写出来就能算出一个结果。
- **语句（statement）** 像「一句命令」—— 它**做一件事**，比如让变量记住一个值、让程序走哪个分支。

```text
3 + 5            ← 表达式，值是 8
"你好" + "世界"    ← 表达式，值是 "你好世界"
x > 10           ← 表达式，值可能是 True 或 False
x = 3 + 5        ← 语句（赋值语句），它把右边表达式的值交给变量 x
if x > 10: ...   ← 语句（if 语句）
```

💡 记忆口诀：**表达式一定有值，语句负责做事。**

## 三、学习重点

### 重点 1：表达式的「求值」过程

```python
price = 10
count = 3
total = price * count + 5   # 先算 price * count 得 30，再加 5 得 35，最后交给 total
```

理解求值顺序，才能看懂复杂表达式。

### 重点 2：优先级记不住就加括号

优先级表不用死背，**记不住就用括号**，括号内先算：

```python
(2 + 3) * 4      # 20，明确表示先算加法
2 + 3 * 4        # 14，乘法优先
```

✅ 结论：**括号不是给 Python 看的，是给读代码的人看的。**

### 重点 3：字符串格式化首选 f-string

```python
name = "小明"
age = 18
print(f"{name} 今年 {age} 岁")   # f-string：最简洁、最推荐
```

### 重点 4：条件表达式让简单的 if-else 缩成一行

```python
level = "成年" if age >= 18 else "未成年"
```

### 重点 5：推导式是「一行造容器」

```python
squares = [x * x for x in range(5)]      # [0, 1, 4, 9, 16]
evens = [x for x in range(10) if x % 2 == 0]   # [0, 2, 4, 6, 8]
```

## 四、⚠️ 常见误区提示（务必看）

| # | 误区 | 真相 |
| --- | --- | --- |
| 1 | 以为 `0.1 + 0.2 == 0.3` 是 `True` | 实际是 `False`，浮点数有精度误差，比较时用 `round()` 或 `math.isclose()` |
| 2 | 以为 `7 / 2` 得整数 `3` | `/` 永远返回 `float`，得 `3.5`；要整数用 `//` |
| 3 | 以为 `-7 // 2` 是 `-3` | Python 向下取整，结果是 `-4`（不是向零取整） |
| 4 | 以为 `1 < x < 10` 会算两次 | 链式比较等价于 `1 < x and x < 10`，且 **`x` 只求值一次** |
| 5 | 以为 `"0"`、`"False"` 是假 | 只有**空字符串**为假，`bool("0")` 是 `True` |
| 6 | 以为 `[]`、`{}`、`0`、`None` 是假 | 确实为假，但要记全：空容器、`0`、`0.0`、`""`、`None` 都是假 |
| 7 | `x = y = []` 以为得到两个列表 | 是两个变量指向**同一个**列表，改一个另一个也变，要独立就用两行分别赋值 |
| 8 | 以为 `x == y` 和 `x is y` 一样 | `==` 比**值**，`is` 比**是不是同一个对象** |
| 9 | `"abc" + 1` | 类型不同不能直接 `+`，字符串和数字拼接必须 `str(1)` 或改用 f-string |
| 10 | 推导式里忘了方括号 | `(x for x in range(3))` 是生成器不是列表，初学阶段先用 `[]` |
