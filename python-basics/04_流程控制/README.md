## 四、核心概念速查

### 1. 三种流程结构

```
顺序结构          条件结构（分支）        循环结构（重复）
  语句1              if 条件:               while 条件:
  语句2                分支A                   重复做的事
  语句3              else:                   for x in 序列:
                        分支B                    重复做的事
按顺序执行         二选一 / 多选一         反复执行直到结束
```

### 2. ⚠️ 缩进 —— Python 最容易出错的地方

Python **没有大括号**，靠**缩进**划分代码块。这是 Python 的第一铁律。

```python
if age >= 18:
    print("成年")        # 缩进 4 空格 -> 属于 if 内部
print("结束")            # 没有缩进   -> 属于 if 外部，总是执行
```

常见的三种缩进报错：

| 报错 | 含义 | 怎么修 |
| --- | --- | --- |
| `IndentationError: expected an indented block` | 该缩进的地方没缩进 | `if`/`for`/`while` 冒号下面那行要缩进 |
| `IndentationError: unexpected indent` | 不该缩进的地方多缩进了 | 检查空行、文件开头是否有空格 |
| `IndentationError: unindent does not match...` | 缩进量对不上 | 统一用 4 个空格，别混用 Tab |

✅ **建议：全部用 4 个空格，不要混用 Tab 和空格**（VSCode 可以设置「将 Tab 转为空格」）。

### 3. while 和 for 怎么选？

| 场景 | 用什么 | 例子 |
| --- | --- | --- |
| 知道要循环几次 / 遍历容器 | `for` | 遍历列表、求 1~100 的和 |
| 不知道要循环几次，靠条件定 | `while` | 猜数字、拆数字直到为 0、游戏主循环 |
| 需要死循环 + 内部判断退出 | `while True` + `break` | 服务器监听、菜单循环 |

### 4. ⭐ 循环的 else 子句（最容易被忽略的语法）

```python
for x in 列表:
    if 找到了:
        break
else:
    print("循环没被 break 打断，说明一个都没找到")
```

| 情况 | else 执行吗？ |
| --- | --- |
| 循环正常跑完（**没有 break**） | ✅ 执行 |
| 中途遇到 **break** 提前退出 | ❌ 不执行 |

> 💡 记忆口诀：**「没 break 才 else」**。`while...else` 规则完全相同。
> 最经典的用法是判断质数：`break` 说明找到了因子（不是质数），走到 `else` 才是质数。

### 5. break / continue / pass 的区别

| 关键字 | 作用 | 生活类比 |
| --- | --- | --- |
| `break` | 立刻结束**整个循环** | 吃到坏包子，整筐都不吃了 |
| `continue` | 只跳过**这一轮**，继续下一轮 | 3 楼没人，跳过，继续发 4 楼 |
| `pass` | **什么都不做**，纯占位 | 先留个空位，以后再填 |

## 五、⚠️ 常见误区 Top 6（务必看）

### 误区 1：忘记更新计数器 → 死循环

```python
# ❌ 错误（会让程序卡死，永远停不下来）
i = 1
while i <= 5:
    print(i)          # i 永远是 1，条件永远成立！

# ✅ 正确：循环体里必须修改条件依赖的变量
i = 1
while i <= 5:
    print(i)
    i += 1            # 这一行就是「逃生门」，缺了它程序就卡住
```

> ✅ **万能保险**：写 `while True:` 时，内部必须有一条能到达的 `break`。
> 例如：`while True: ... if count > 5: break`。

### 误区 2：`=` 和 `==` 搞混

| 写法 | 含义 |
| --- | --- |
| `x = 5` | 赋值：把 5 放进 x |
| `x == 5` | 判断：x 等于 5 吗？返回 True/False |

> 💡 `if x = 5:` 在 Python 里是**语法错误**，程序会直接报错，不会悄悄出错，这是好事。

### 误区 3：`if x == "a" or "b"` —— 条件永远为真

```python
role = "guest"
# ❌ 错误：被理解成 (role == "a") or ("b")，"b" 非空字符串永远为真！
if role == "admin" or "manager":
    print("有权限")        # guest 也会打印"有权限"，非常危险

# ✅ 正确：每个条件都写完整
if role == "admin" or role == "manager":
    print("有权限")
```

### 误区 4：用浮点数做循环条件

```python
# ❌ 危险：0.1 在二进制里存不准，x 可能永远不等于 1.0
x = 0.0
while x != 1.0:
    x += 0.1          # 可能死循环！

# ✅ 正确做法一：用整数循环，最后再换算
tenths = 0
while tenths < 10:
    tenths += 1
result = tenths / 10

# ✅ 正确做法二：用容差比较
epsilon = 1e-9
if abs(x - 1.0) < epsilon:
    print("足够接近 1.0")
```

> ⚠️ 记住这个经典现象：`0.1 + 0.2 == 0.3` 结果是 **False**（因为浮点误差）。

### 误区 5：遍历列表时修改列表

```python
# ❌ 错误：边遍历边删，索引会错位，漏删元素
nums = [1, 2, 3, 2, 4]
for n in nums:
    if n == 2:
        nums.remove(n)      # 删完索引前移，会跳过元素

# ✅ 正确做法一：遍历副本
for n in nums[:]:           # [:] 创建副本
    if n == 2:
        nums.remove(n)

# ✅ 正确做法二：生成新列表（推荐，最清晰）
nums = [n for n in [1, 2, 3, 2, 4] if n != 2]
```

### 误区 6：range 边界搞错

```python
list(range(5))          # [0, 1, 2, 3, 4]      共 5 个，不含 5
list(range(1, 10))      # [1, 2, ..., 9]       共 9 个！想要 10 得写 range(1, 11)
list(range(1, 10, 2))   # [1, 3, 5, 7, 9]      步长 2
list(range(5, 0, -1))   # [5, 4, 3, 2, 1]      步长为负表示倒着数
```

> 💡 记忆口诀：**「起点包括，终点不包括」**（左闭右开）。
> ⚠️ `range` 只接受整数，`range(0.0, 1.0, 0.1)` 会报 `TypeError`。
