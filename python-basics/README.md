# Python 基础语法学习资料

这是一份面向**零基础初学者**的 Python 语法自学资料包：每个知识点都配了可以直接运行的示例文件，你只需要在 VSCode 里**逐个文件打开并按顺序运行**，边看输出边改代码，就能把 Python 基础语法过一遍。

---

## 一、环境准备

### 1. 确认 Python 已安装

打开 VSCode 的终端（菜单 `终端 → 新建终端`，快捷键 `Ctrl + 反引号`），输入：

```bash
python --version
```

看到 `Python 3.x.x` 就说明安装成功。如果提示找不到命令，可以依次尝试：

```bash
py --version
python3 --version
```

都不行的话，去 [python.org](https://www.python.org/downloads/) 下载安装，安装时**务必勾选 `Add Python to PATH`**。

### 2. 在 VSCode 中运行 .py 文件

有两种方式，任选其一：

| 方式 | 操作 | 说明 |
| --- | --- | --- |
| 终端命令 | `python 文件名.py` | 最通用，能清楚看到报错信息 |
| 运行按钮 | 打开 .py 文件，点右上角 ▶ 运行 | 需要安装 Python 扩展 |

> 小技巧：在终端里输入文件名前几个字母，按 `Tab` 键可以自动补全。

### 3. 建议安装的 VSCode 扩展

- **Python**（Microsoft 官方，必装）——提供语法高亮、运行按钮、调试功能
- **Pylance**（一般随 Python 扩展自动安装）——更聪明的代码提示

### 4. 学习姿势

- 每个示例文件**先运行一遍看输出**，再回头读代码；
- 读代码时**动手改数字、改变量，再运行看结果变化**——这是学得最快的方式；
- 遇到报错别慌，Python 的报错信息会告诉你**出错的行号**和**原因**，从最后一行往前读。

## 二、学习路线

总计约 **2 周**，每天投入 1-2 小时即可。

| 主题 | 目录 | 核心知识点 | 建议用时 |
| --- | --- | --- | --- |
| 第 1 章 变量 | `01_变量/` | 变量与命名规则、基本数据类型、类型转换、可变与不可变 | 2 天 |
| 第 2 章 运算符 | `02_运算符/` | 算术、比较、逻辑、赋值、位运算、成员与身份运算符 | 2 天 |
| 第 3 章 表达式 | `03_表达式/` | 表达式与语句、运算符优先级、字符串表达式、条件表达式、推导式入门、常见陷阱 | 2 天 |
| 第 4 章 流程控制 | `04_流程控制/` | if 分支、条件嵌套、while 循环、for 循环、循环控制、嵌套循环、常见陷阱 | 3 天 |
| 第 5 章 函数 | `05_函数/` | 定义与调用、参数类型、可变参数、返回值、作用域、递归、函数作为对象 | 3 天 |
| 第 6 章 综合练习 | `06_综合练习/` | 跨主题综合题、迷你项目（成绩管理、猜数字游戏） | 2 天 |

每个主题目录内的文件建议按**编号顺序**学习：

1. `README.md` —— 先看本章知识点讲解
2. `01_xxx.py`、`02_xxx.py` …… —— 按编号运行示例
3. `练习题.py` —— 自己动手做题
4. `练习题_答案.py` —— 做完再对答案

## 四、使用建议

推荐的学习闭环是这 5 步：

1. **先读 README** —— 打开主题目录的 `README.md`，了解这一章要学什么；
2. **跑示例** —— 逐个运行编号 .py 文件，观察输出，注意代码和输出的对应关系；
3. **改示例** —— 把示例里的数字、字符串、条件改掉再跑一次，看结果怎么变；**改坏了更好，报错信息就是最好的老师**；
4. **做练习** —— 打开 `练习题.py`，每一题自己动手写出代码再运行；
5. **对答案** —— 最后打开 `练习题_答案.py` 对比，重点看思路不同的地方，而不是逐字比对。

进入 `06_综合练习/` 后，先做综合基础题，再做进阶题，最后完成两个迷你项目。

## 五、学习检查清单

学完每一章后，对照下面的自测项打个勾。**全部勾上再进入下一章**。

### 第 1 章 变量

- [ ] 我能说出变量命名的规则（字母/数字/下划线、不能数字开头、区分大小写），并知道 `class`、`for` 这类关键字不能当变量名
- [ ] 我能分清 `int`、`float`、`str`、`bool`、`list`、`tuple`、`dict`、`set` 这些基本类型，并会用 `type()` 查看类型
- [ ] 我能用 `int()`、`float()`、`str()` 完成类型转换，并知道"字符串 `'123'` 不等于数字 `123`"
- [ ] 我能解释列表是可变、元组和字符串是不可变的

### 第 2 章 运算符

- [ ] 我能熟练使用 `+ - * / // % **`，并知道 `7 / 2` 得 `3.5` 而 `7 // 2` 得 `3`
- [ ] 我能用 `== != > < >= <=` 做比较，并理解 `=` 和 `==` 的区别
- [ ] 我能用 `and`、`or`、`not` 组合条件，并知道它们有"短路"特性
- [ ] 我能说出 `in` / `not in` 和 `is` / `is not` 分别判断什么

### 第 3 章 表达式

- [ ] 我能说出常见运算符的优先级，必要时会用括号让代码更清晰
- [ ] 我会用条件表达式 `a if 条件 else b` 写一行简单的分支
- [ ] 我能读懂并写出简单的列表推导式，如 `[x * x for x in range(5)]`
- [ ] 我知道 `x = y = []` 这种写法会让两个变量指向同一个列表

### 第 4 章 流程控制

- [ ] 我能用 `if / elif / else` 写出多分支判断，并注意缩进
- [ ] 我能用 `while` 和 `for` 写循环，并知道什么时候用哪个
- [ ] 我会用 `break` 跳出循环、`continue` 跳过本次、`else` 处理循环正常结束
- [ ] 我能用 `range()` 控制循环次数，并会写简单的嵌套循环（如打印乘法表）

### 第 5 章 函数

- [ ] 我能用 `def` 定义函数并调用，知道参数和返回值的作用
- [ ] 我能区分位置参数、关键字参数、默认参数，并会用 `*args` / `**kwargs`
- [ ] 我理解局部变量和全局变量的区别，知道函数内部要改全局变量需要 `global`
- [ ] 我能读懂递归函数的执行过程（如阶乘、斐波那契）

### 第 6 章 综合练习

- [ ] 我能在不看答案的情况下独立完成综合练习的基础题
- [ ] 我能用函数把一个稍大的问题拆成几个小函数来解决
- [ ] 我能独立运行并改动两个迷你项目，说出每一部分代码的作用
