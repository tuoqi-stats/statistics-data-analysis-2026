## 三、每个文件的学习方法（重要）

这套示例文件是按"**注释即讲义**"的思路写的，用错方法会白看：

| 步骤 | 做什么 | 为什么这样做 |
| --- | --- | --- |
| 1️⃣ 先跑一遍 | 直接运行，先看整体输出长什么样 | 建立"大概在讲什么"的印象 |
| 2️⃣ 再读代码 | 从上往下读，**每行 print 上方都有"预期输出"注释** | 这句注释就是你的答案对照表 |
| 3️⃣ 蒙一下 | 遮住注释，猜结果，再看输出验证 | 这一步最能暴露理解漏洞 |
| 4️⃣ 改代码 | 把数字、字符串改掉再跑，看结果怎么变 | 主动探索比被动阅读有效 10 倍 |
| 5️⃣ 看完小结 | 拉到最后看 `# ---------- 小结 ----------` | 快速回顾，确认没漏知识点 |

> ⚠️ **改坏了是好事！** 删掉括号、把 `==` 写成 `=`、把 `//` 换成 `/`，
> 然后看 Python 报什么错。报错信息是最好的老师，读懂了就再也不怕它。

## 四、知识点速查表

### 4.1 算术运算符

| 运算符 | 名称 | 例子 | 结果 | 备注 |
| --- | --- | --- | --- | --- |
| `+` | 加 | `7 + 2` | `9` | 字符串/列表上表示"拼接" |
| `-` | 减 | `7 - 2` | `5` | |
| `*` | 乘 | `7 * 2` | `14` | 字符串/列表上表示"重复" |
| `/` | 除 | `7 / 2` | `3.5` | ⚠️ 结果**永远是 float** |
| `//` | 整除 | `7 // 2` | `3` | 向下取整，`-7 // 2` 是 `-4` |
| `%` | 取模 | `7 % 2` | `1` | 取余数，判断奇偶/倍数常用 |
| `**` | 幂 | `7 ** 2` | `49` | ⚠️ 不是 `^`，Python 整数不溢出 |

### 4.2 比较运算符

| 运算符 | 含义 | 例子 | 结果 |
| --- | --- | --- | --- |
| `==` | 等于 | `3 == 3` | `True` |
| `!=` | 不等于 | `3 != 4` | `True` |
| `>` | 大于 | `3 > 4` | `False` |
| `<` | 小于 | `3 < 4` | `True` |
| `>=` | 大于等于 | `4 >= 4` | `True` |
| `<=` | 小于等于 | `4 <= 3` | `False` |

✅ 特点：结果永远是 `bool`（`True` / `False`）；支持链式写法 `0 < x < 10`。

### 4.3 逻辑运算符

| 运算符 | 含义 | 真值规则 | 短路行为 |
| --- | --- | --- | --- |
| `and` | 与 | 全真才真 | 遇**假**即停 |
| `or` | 或 | 有真就真 | 遇**真**即停 |
| `not` | 非 | 真假颠倒 | — |

优先级：`not` > `and` > `or`。

### 4.4 复合赋值运算符

| 写法 | 等价于 | 例子（x=5） | 结果 |
| --- | --- | --- | --- |
| `+=` | `x = x + y` | `x += 3` | `8` |
| `-=` | `x = x - y` | `x -= 3` | `2` |
| `*=` | `x = x * y` | `x *= 3` | `15` |
| `/=` | `x = x / y` | `x /= 2` | `2.5` ⚠️ 变 float |
| `//=` | `x = x // y` | `x //= 2` | `2` |
| `%=` | `x = x % y` | `x %= 2` | `1` |
| `**=` | `x = x ** y` | `x **= 2` | `25` |

### 4.5 位运算符（了解即可）

| 运算符 | 名称 | 例子 | 结果 | 一句话理解 |
| --- | --- | --- | --- | --- |
| `&` | 按位与 | `5 & 3` | `1` | 都是 1 才是 1 |
| `\|` | 按位或 | `5 \| 3` | `7` | 有 1 就是 1 |
| `^` | 按位异或 | `5 ^ 3` | `6` | 不同才是 1（⚠️ 不是乘方） |
| `~` | 按位取反 | `~5` | `-6` | 公式 `~x = -(x+1)` |
| `<<` | 左移 | `5 << 1` | `10` | 相当于 ×2 的 n 次方 |
| `>>` | 右移 | `20 >> 1` | `10` | 相当于整除 2 的 n 次方 |

### 4.6 成员与身份运算符

| 运算符 | 含义 | 例子 | 结果 |
| --- | --- | --- | --- |
| `in` | 在里面 | `3 in [1,2,3]` | `True` |
| `not in` | 不在里面 | `5 not in [1,2,3]` | `True` |
| `is` | 是同一个对象 | `a is None` | `bool` |
| `is not` | 不是同一个对象 | `a is not None` | `bool` |

## 五、运算符优先级总表

从高到低（**先算上面的，后算下面的**）：

| 优先级 | 运算符 | 说明 | 结合方向 |
| --- | --- | --- | --- |
| 1 | `( )` | 括号 | — |
| 2 | `**` | 幂运算 | ⚠️ 从右往左 |
| 3 | `+x` `-x` `~x` | 一元正负号、按位取反 | 从右往左 |
| 4 | `*` `/` `//` `%` | 乘、除、整除、取模 | 从左往右 |
| 5 | `+` `-` | 加、减 | 从左往右 |
| 6 | `<<` `>>` | 移位 | 从左往右 |
| 7 | `&` | 按位与 | 从左往右 |
| 8 | `^` | 按位异或 | 从左往右 |
| 9 | `\|` | 按位或 | 从左往右 |
| 10 | `==` `!=` `>` `<` `>=` `<=` `in` `not in` `is` `is not` | 比较、成员、身份 | 从左往右 |
| 11 | `not` | 逻辑非 | 从右往左 |
| 12 | `and` | 逻辑与 | 从左往右 |
| 13 | `or` | 逻辑或 | 从左往右 |
| 14 | `=` `+=` `-=` `*=` `/=` `//=` `%=` `**=` 等 | 赋值（最低） | 从右往左 |

✅ **背不下来完全没关系**——记住一句话就够了：

> **拿不准就加括号！** 括号不花钱，还能让代码意图一目了然。
>
> ```python
> # 不推荐（虽然结果正确）
> result = a + b * c ** 2 > 100 and d or e
>
> # 推荐（一眼看懂）
> result = ((a + b * (c ** 2)) > 100 and d) or e
> ```

## 六、学习重点（🌟 这些必须掌握）

### 🌟 重点 1：`/` 和 `//` 的区别

```python
print(7 / 2)    # 3.5   ← 除法，结果带小数
print(7 // 2)   # 3     ← 整除，只要"够几个完整的"
```

生活类比：`/` 是把西瓜切开看有几块半；`//` 是数能装满几整箱。

### 🌟 重点 2：`==` 和 `=` 是天壤之别

```python
x = 5      # 赋值：把 5 装进 x
x == 5     # 比较：x 等于 5 吗？得到 True
```

心里默念：`=` 读作"**装进**"，`==` 读作"**等于吗**"。写错不报错、结果却全错，
是本章最难查的 bug。

### 🌟 重点 3：短路求值

```python
denominator = 0
result = denominator != 0 and 10 / denominator > 1   # 安全！不会报错
```

`and` 遇到假就立刻停下，右边的除法根本不会执行——所以除了省计算，
它还能**防错**。这是逻辑运算符最实用的价值。

### 🌟 重点 4：`and` / `or` 返回的是操作数本身

```python
print("" or "默认值")     # 默认值   ← 不是 True！
print(5 and 100)          # 100      ← 不是 True！
```

`or` 返回第一个**真值**，`and` 返回第一个**假值**。所以才有这种好用的一行写法：

```python
nickname = user_input or "游客"          # 兜底默认值
```

### 🌟 重点 5：`==` 和 `is` 该用哪个

| 场景 | 用哪个 | 原因 |
| --- | --- | --- |
| 比较数字、字符串、列表的内容 | `==` | 你要的是"值相等" |
| 判断是不是 `None` | `is` | `None` 全局唯一，官方推荐 |
| 判断是不是 `True` / `False` | `is` | 布尔值也是单例 |
| 判断元素在不在容器里 | `in` | 这才是成员判断的正道 |

> ✅ **口诀：值相等用 `==`，和 `None` 打交道用 `is`，在不在用 `in`。**

## 七、⚠️ 常见误区（这些坑几乎人人都会踩）

### ⚠️ 误区 1：以为 `7 / 2` 等于 3

```python
print(7 / 2)    # 3.5，不是 3！
type(7 / 2)     # <class 'float'>，哪怕能整除也是 float
print(10 / 2)   # 5.0，注意那个 .0
```

### ⚠️ 误区 2：以为负数整除是"砍掉小数"

```python
print(-7 // 2)   # -4，不是 -3！
```

`//` 是**向下取整**（数轴上往左走），不是截断取整。这也是为什么
`-7 // 2 == -4`、`-7 >> 1 == -4`。

### ⚠️ 误区 3：用 `^` 做乘方

```python
print(2 ** 3)   # 8    ← 这才是乘方
print(2 ^ 3)    # 1    ← 这是异或！新手最常犯的错之一
```

### ⚠️ 误区 4：用 `==` 比较浮点数

```python
print(0.1 + 0.2 == 0.3)          # False  ← 会翻车
print(0.1 + 0.2)                 # 0.30000000000000004
print(round(0.1 + 0.2, 2) == 0.3)          # True，用 round
print(abs((0.1 + 0.2) - 0.3) < 1e-9)       # True，用"差值足够小"
```

> ⚠️ 更阴险的是它**有时对有时错**：`0.1 + 0.2 + 0.7 == 1.0` 居然是 `True`。
> 所以规矩是：只要涉及浮点，就别用 `==` 直接比。

### ⚠️ 误区 5：以为 `b = a` 是复制

```python
a = [1, 2]
b = a              # ⚠️ 只是多贴了一个名字，不是复制！
b += [3]
print(a)           # [1, 2, 3]  ← a 被"牵连"了
```

因为列表的 `+=` 是**原地修改**（相当于 `extend`）。
要真正的副本，用 `a[:]`、`list(a)` 或 `a.copy()`。

### ⚠️ 误区 6：以为字符串 `"0"` 是假值

```python
if "0":     # 会执行！非空字符串都是真
if 0:       # 不会执行
```

**假值只有这几种**：`False`、`0`、`0.0`、`""`、`[]`、`()`、`{}`、`set()`、`None`。
记住：**"空"和"零"算假，其他都算真**（负数、`[0]`、`" "` 都是真）。

### ⚠️ 误区 7：写 `x == 1 or 2 or 3`

```python
x = 5
print(x == 1 or 2 or 3)   # 输出 2，不是 False！
```

因为 `False or 2` 返回 `2`（看到真值就停）。正确写法：

```python
print(x in (1, 2, 3))     # False
```

### ⚠️ 误区 8：用 `is` 比数字和字符串

```python
print(1000 is 1000)                  # True  ← 字面量被合并成同一个常量，看起来"对"
print(int("1000") is int("1000"))    # False ← 运行时新建两个对象，立刻露馅
```

有两套机制会让 `is` 比数字时"碰巧"返回 `True`：
**① 小整数缓存**（-5~256 的整数提前创建好重复使用），
**② 常量合并**（同一代码块里相同的字面量在编译期被合并成一个对象，连 257、1000 也适用）。
字符串还有类似的**驻留机制**。

**这正是它最危险的地方**——你写 `a = 1000; b = 1000` 时测出来是 `True`，
于是放心地用了 `is`，结果上线后值变成从数据库/输入算出来的，立刻变成 `False`，
bug 就此诞生。

> ✅ 判断内容和值，永远用 `==`。只有 `None`、`True`、`False` 才用 `is`。

### ⚠️ 误区 9：累乘器初始化为 0

```python
product = 0
for i in range(1, 6):
    product *= i
print(product)     # 0  ← 0 乘任何数都是 0，全军覆没
```

**累加器从 0 开始，累乘器从 1 开始**——这是两种"单位元"。

### ⚠️ 误区 10：以为 `not a = b` 或把 `not` 优先级记错

```python
print(not a and b)      # 等价于 (not a) and b，不是 not (a and b)！
```

`not` 的优先级**高于** `and`、`or`。想取反整个表达式，记得加括号
写 `not (a and b)`。

## 九、本章小结

运算符是 Python 语法的"肌肉"——后面写 `if` 判断、写循环、写函数，
全都是在组合使用本章这些符号。所以**这一章值得多花点时间**。

三句话带走：

1. **算术靠 `//` 和 `%` 打配合**，`/` 的结果永远是小数。
2. **逻辑运算会短路，也会返回操作数本身**，这两点让你的代码更简洁也更安全。
3. **`==` 比值，`is` 比身份，`in` 比存在**——用错了不一定报错，但一定出 bug。
