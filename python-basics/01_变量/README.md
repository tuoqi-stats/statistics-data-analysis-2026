## 一、先建立一个直觉：变量是"贴标签"，不是"装盒子"

很多教程会告诉你"变量是一个盒子，值放在盒子里"。这个说法能帮你入门，但**很快就会害你**。

更准确的模型是：

| 现实世界 | Python 世界 |
| --- | --- |
| 一个储物箱（数据本身） | 对象（object） |
| 贴在箱子上的纸条（写着名字） | 变量 |
| 同一个箱子可以贴好几张纸条 | `b = a` 时两个变量指向同一对象 |
| 撕掉一张纸条，箱子还在 | `del a` 只删名字，不删数据 |
| 箱子里的东西变了，所有纸条"看到"的都是新的 | 可变对象被修改，所有引用都变 |

记住一句话：**变量是标签，值才是盒子。**

## 四、学习重点

1. **赋值是从右往左的**
   `score = score + 10` 不是数学等式，含义是"先算右边，再把结果贴到 `score` 上"。

2. **`b = a` 不复制数据**
   这两个名字指向**同一个对象**。对可变对象（列表、字典）来说，改一个另一个也会变。
   需要独立副本时必须显式复制，例如 `b = a[:]` 或 `b = list(a)`。

3. **分清可变与不可变**
   - 不可变：`int`、`float`、`str`、`bool`、`None`、`tuple`
   - 可变：`list`、`dict`、`set`
   不可变类型"修改"其实是换了新对象；可变类型能原地改。

4. **`==` 比值，`is` 比身份**
   比内容一律用 `==`；`is` 只推荐用于判断 `None`（`if x is None`）。
   ⚠️ 不要用 `is` 比较数值或字符串：`int("1000") is int("1000")` 是 `False`，
   而 `int("100") is int("100")` 却是 `True`（小整数缓存），结果完全靠不住。

5. **类型转换要主动、要小心**
   Python 不会帮你把 `"3"` 和 `4` 自动相加，必须先 `int("3")`。
   转换失败会抛异常，写代码时要有心理准备。

6. **命名要见名知义**
   用 `user_name` 而不是 `a`、`x1`、`data2`。变量名是给未来的自己看的。

## 五、常见误区 ⚠️

| # | 误区 | 说明 | 对应文件 |
| --- | --- | --- | --- |
| 1 | **以为 `b = a` 是复制** ⚠️⚠️ | 只是多贴一张标签，改一个另一个也变。要副本请用 `a[:]` / `copy` | 05 |
| 2 | **链式赋值套可变对象** ⚠️⚠️ | `a = b = []` 让三个变量共享同一个列表，追加元素会"三个一起变" | 05 |
| 3 | **`int(3.9)` 以为是 4** | 是**截断**成 3（向 0 取整），不是四舍五入；要四舍五入用 `round()` | 03 |
| 4 | **`int("3.5")`** | 直接报 `ValueError`。必须先 `float()`：`int(float("3.5"))` | 03 |
| 5 | **`bool("0")` 以为是 False** | `"0"` 是**非空字符串**，是 `True`；`bool("False")` 也是 `True` | 03 |
| 6 | **以为 `0.1 + 0.2 == 0.3`** | 浮点数不精确，结果是 `0.30000000000000004`，比较要用 `round()` 或容差 | 02 |
| 7 | **用 `is` 比较数值/字符串** ⚠️⚠️ | `int("1000") is int("1000")` 是 `False`，但 `int("100") is int("100")` 是 `True`（小整数缓存），结果不稳定。`is` 只该用于 `None` | 04 |
| 8 | **小整数缓存与常量合并混为一谈** | 缓存是运行时机制（-5~256）；同代码块相同字面量的合并是**编译期**行为，是两回事 | 04 |
| 9 | **以为"只有像标识符的字符串才被驻留"** | 实测 `"hello"` 和 `"hello world!"` 都驻留；但 `"".join(...)` 拼出来的不驻留 —— 规则不可依赖，一律用 `==` | 04 |
| 10 | **用 `=` 做判断** | `if x = 1:` 是语法错误，判断要用 `==` | 05 |
| 11 | **拿内置名当变量名** | `list = [1,2]`、`sum = 10` 会覆盖内置功能，后患无穷 | 01 / 05 |
| 12 | **中文标点** | `print（"hi"）` 用了全角括号 → `SyntaxError`；代码里必须是英文半角 | 05 |
| 13 | **变量未定义 / 大小写写错** | 都报 `NameError`；`myScore` 和 `myscore` 是两个不同变量 | 05 |
