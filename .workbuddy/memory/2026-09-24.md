### 关键约定（后续扩展请沿用）

- 每个 .py **首行** `# -*- coding: utf-8 -*-`（Windows 下中文/emoji 输出必须）
- 结构：三引号 docstring（学什么/怎么运行/预计输出）→ `# ===== 标题 =====` 分节 → 每行 print **前**加 `# 预期输出：` 注释 → 末尾 `# ---------- 小结 ----------`
- **禁止 `input()` 和真实死循环**——用户要的是秒级跑完；演示死循环用带上限的安全写法或把错误代码注释掉
- 所有 .py 必须实测可运行：`C:\Users\HUAWEI\.workbuddy\binaries\python\versions\3.13.12\python.exe`（注意该路径 `--version` 实际报 3.13.14）
- 结论必须**实测**而非凭记忆写。本次子 agent 实测修正了多处经典错误认知：
  - `int("３")`（全角）实际**成功**返回 3，不报错
  - `a=257; b=257; a is b` 因**编译期常量合并**为 True；稳定反例是 `int("1000") is int("1000")` → False
  - 小整数缓存范围 -5~256：`int('256') is int('256')` True，`int('257')` False
  - `"hello world!"` 实测也被驻留；`"".join(['hel','lo']) is 'hello'` → False
  - `0.1+0.2+0.7` 反而精确等于 1.0；`0.7*3 = 2.0999999999999996` 才暴露浮点尾巴
