# Concept Learning Generator（通用概念学习资料生成）

## 用途

当用户给出**任意一个 AI 或技术概念名称**（例如"注意力机制""梯度消失""RAG""对比学习""联邦学习"等），本 Skill 指导生成一份**结构化、可长期复习**的概念学习资料。

> 不限定具体概念——任何 AI/技术概念都适用。本 Skill 是通用模板，而非针对某几个固定概念。

## 触发条件

- 用户说"帮我学习/讲讲/解释一下 XXX 概念"，并希望得到一份**系统学习资料**（而非一句话定义）。
- 用户给出概念名称，要求生成笔记 / 学习卡片 / 复习材料。
- 用户在"统计与数据分析""机器学习""深度学习"等课程学习中遇到新概念，希望整理成结构化资料。

## 输入

- **必需**：一个概念名称（中英文均可）。
- **可选**：学习者背景（初学者 / 有基础 / 工程实践向）、重点方向、期望深度。

## 输出结构（固定六大模块）

对每个概念，按以下六个模块依次输出，**缺一不可**：

### 模块 1 · 个人通俗解释

- 用**自己的话**重新组织，不照搬百科原文。
- 假设读者**无该领域背景**，能用一两句生活化比喻讲清楚"它本质上在解决什么问题"。
- 控制在 3–5 句话以内；必要时配一个非技术类比。
- 避免一上来就堆术语；先建立直觉，再引入正式名词。

### 模块 2 · 核心机制

- 讲清楚"它具体怎么工作"：关键步骤、关键公式/结构、输入输出关系。
- 如涉及数学：写出**核心公式**并逐项解释符号含义，标注单位与约束条件，不堆砌推导。
- 如涉及结构/流程：用文字 +（必要时）示意描述讲清数据/信号怎么流动。
- 区分"概念本身"与"它的某个具体实现"，先讲通用的、再点出变体。

### 模块 3 · 真实应用场景

- 列 **3 个以上**真实落地场景，每个场景说明：用在什么产品/环节 + 为什么用它（解决了什么痛点）。
- 优先选用户可能接触到的真实产品/业务（搜索、推荐、风控、医疗、自动驾驶等），而非泛泛"可用于图像识别"。
- 标注每个场景中该概念扮演的角色（核心方法 / 辅助组件 / 替代方案之一）。

### 模块 4 · 易混淆边界

- 列出 **2–3 组**容易和本概念混在一起的相关概念，逐组说明：
  - 它和本概念的**关键区别**（一句话点透）；
  - 什么情况该用本概念、什么情况该用那个相关概念。
- 典型混淆类型：上位/下位概念混淆、相似名称混淆、互补方法混淆、新旧方法混淆。
- 用对比表格呈现更清晰（概念 | 与本概念的关键差异 | 何时用哪个）。

### 模块 5 · 权威参考链接

- 提供 **3 条以上**权威来源，优先级：原始论文 / 官方文档 / 权威教材 > 高质量综述 > 可信博客。
- 每条链接标注：类型（论文/文档/教程/综述）+ 一句话说明"为什么值得看 / 侧重什么"。
- 论文须给出**完整标题 + 作者 + 年份 + 会议/期刊**，尽量给可访问链接（arXiv / 官方）。
- 严禁编造链接；如不能确认真实 URL，则只给可核对的标题与出处，并注明"需自行检索"。

### 模块 6 · 自测思考题

- 出 **3–5 道**思考题，从浅到深覆盖：
  - 第 1 题：复述/判断类（检验是否理解定义）；
  - 第 2 题：机制类（检验是否掌握内部原理）；
  - 第 3 题：辨析类（检验能否与相关概念区分）；
  - 第 4 题起（可选）：应用/迁移类（给定场景判断该不该用、怎么用）。
- 思考题**只出题，不直接给答案**；可在题后附一句"提示方向"，但不写完整解答。
- 鼓励需要推理/举例而非查定义才能答的题目。

## 生成流程

1. **确认概念**：明确用户给的概念名称与外延（若概念有歧义，先点出歧义并按最常见含义展开，注明"此处按 XX 理解"）。
2. **事实核查**：对机制、公式、论文出处等关键事实进行检索/核实，不凭记忆硬写；无法核实的内容要降级处理或注明不确定性。
3. **按六大模块输出**：严格按上述顺序与要求生成，每个模块有清晰标题。
4. **口径统一**：深度匹配学习者背景；初学者侧重模块 1、3、6，有基础者加重模块 2、4。
5. **自检**：输出前回看一遍——有没有照抄百科、链接是否真实、思考题是否够浅到深。修正后再交付。

## 输出格式建议

- 以 **Markdown** 输出，模块标题用二级标题（`## 模块 X · 名称`）。
- 公式用 LaTeX（`$...$` 行内 / `$$...$$` 独立行）。
- 对比、场景类内容优先用表格。
- 整体控制在能让学习者在 10–15 分钟读完并形成记忆的篇幅。

## 质量底线（必须满足）

- 六模块齐全，顺序固定。
- 通俗解释是"自己的话"，不是百科原文复述。
- 每个公式都有符号解释，不裸抛公式。
- 所有参考链接真实可核；论文给出完整题录信息。
- 思考题只出题不给答案，且有由浅入深的梯度。

## 使用示例

> 用户：帮我学习一下"注意力机制"。
> 触发本 Skill → 按六大模块生成结构化学习资料，输出 Markdown 笔记。
