# concept-material-generator — AI 概念学习资料生成器

接收任意 AI / 机器学习 / 统计学习概念名词，产出一份结构统一、可复习、可检索的个人学习 markdown 文档，统一存放于仓库根目录 `learning-materials/`，逐步沉淀为个人概念知识库。

## 适用场景

- 输入任意概念名词，生成个人学习资料；本 skill 是通用概念学习工具
- **不局限于** Agent、大模型的上下文（Context）、Skill 三个概念——Transformer、RAG、Diffusion、RLHF、MoE、KV Cache、量化、贝叶斯推断、假设检验等任何 AI / 机器学习 / 统计学习概念均可
- 学习深度加深后可对同一概念重新生成；生成前先检查 `learning-materials/` 是否已有同名文档，若已存在，先询问用户选择覆盖还是归档

## 输入信息

| 字段 | 必填 | 说明 |
|------|------|------|
| 概念名词 | 是 | 字符串，待学习的概念名称，中英文均可（如 "RAG"、"注意力机制"、"RLHF"） |

可选补充（不强制）：概念全称或缩写、用户已有的理解或疑问、期望深度（入门 / 进阶）。

## 生成步骤

1. **确认概念**：明确概念的中英文名称与常见缩写；若一词多义，先判断 AI / 数据科学语境下的主流含义，并在文档开头注明所指
2. **查重**：用 Read 工具检查 `learning-materials/` 下是否已有同名文档；存在则先询问用户覆盖或归档
3. **撰写内容**：严格按"输出结构"的 5 部分模板撰写；全文使用简体中文，术语首次出现时标注英文原文
4. **落实链接**：按"资料来源要求"确定第 5 部分的链接，写入前逐条核验可达性，宁缺毋假
5. **自检**：逐项核对"自检要求"清单，未通过项修正后再进入下一步
6. **保存输出**：用 Write 工具将文档保存至 `learning-materials/<概念名>.md`；文件名使用小写 kebab-case——优先概念的通用英文或缩写（如 `rag.md`、`transformer.md`），无通用英文时用拼音（如 `gui-yi-han-shu.md`）
7. **汇报结果**：向用户报告文件完整路径，并用一句话概括每个部分的要点

## 输出结构（固定 5 部分，标题一字不差）

````markdown
# <概念名词>（<英文 / 缩写>）

> 生成日期：YYYY-MM-DD ｜ 类别：AI 概念学习资料

## 1. 概念个人解释
（用大白话和第一人称视角解释这个概念。先类比——"它像什么"，再定义——"它是什么"。2-4 段，禁止术语堆砌。）

## 2. 核心机制或组成
（回答"它为什么能工作、由什么组成"。至少拆解出 2 个组成要素或关键步骤，可用列表、表格或示意说明。）

## 3. 具体应用场景
（它在哪里被真实使用。至少 3 个具体场景，每个场景尽量带真实产品、项目或论文实例，不写空泛描述。）

## 4. 容易混淆的问题或使用边界
（回答"它不是什么、什么时候不该用"。至少包含 1 组"X vs Y"对照，写清适用边界与失效条件。）

## 5. 可核查资料来源链接
（2-5 条真实可访问的公开网页链接，每条附一句话说明"这个来源值得看什么"。）
````

五个部分之外不得添加其他章节；仅允许文件头部的一行元信息（生成日期、类别）。

## 资料来源要求

- **禁止编造链接**。第 5 部分的任何 URL 必须满足以下条件之一：
  1. 本次会话中实际核验过可达（curl 状态码 200）
  2. 高度确信长期稳定存在的权威页面，如 Wikipedia 词条、官方文档页、arXiv 论文页、标准规范页
- 来源优先级：官方文档 / 原始论文 > Wikipedia > 免费在线教科书（NIST Handbook、Penn State STAT 500、StatLect、Think Bayes 等）> 权威机构技术博客（OpenAI、Anthropic、Google Research、Stanford 等）
- 每条链接必须附一句话说明该来源的价值
- 无法核实又无把握时，改写为"建议检索关键词：xxx"，不得输出虚构 URL
- 不使用需要登录或付费才能查看的链接

## 自检要求

写入文件前逐项核对，全部通过方可保存：

- [ ] 文档包含且仅包含固定的 5 个部分，标题一字不差
- [ ] 第 1 部分先类比后定义，无术语堆砌
- [ ] 第 2 部分至少拆解出 2 个组成要素或步骤
- [ ] 第 3 部分至少 3 个具体场景且带实例
- [ ] 第 4 部分至少 1 组 "X vs Y" 对照，并写明使用边界
- [ ] 第 5 部分为 2-5 条真实公开链接且各附说明，写入前已核验可达；无法核实的已改为检索关键词
- [ ] 文件保存路径为 `learning-materials/`，文件名为小写 kebab-case
- [ ] 全文为简体中文，术语首次出现标注英文
- [ ] 保存成功后已向用户报告完整路径
