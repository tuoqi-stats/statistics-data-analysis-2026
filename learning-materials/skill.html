1个人通俗解释

Skill = 新员工的岗位操作手册 大模型很聪明，但不懂业务规则和固定流程。 方案1：每次对话重复说明，麻烦还占用上下文； 方案2：模型微调，成本高、耗时间。 Skill是第三种选择：把做事流程存成手册。 平时只显示简短书名（书脊），不占用桌面； 需要干活时才翻开手册执行，用完合上，桌面清空。 concept‑learning‑generator就是实例，固化生成学习资料的整套流程，不用反复复述要求。

2核心机制

一个 Skill 通常由三个要素组成，缺一不可：

Skill = 说明书(SKILL.md) // 元数据 + 触发条件 + 工作流 + 质量底线
      + 工具/脚本(可选) // 可被调用的函数/资源
      + 触发条件 // 什么场景该加载它
// 智能体按需加载 → 按其工作流执行 → 产出符合质量底线的结果

SKILL.md 的结构（以本页所用 Skill 为例）

  • YAML 元数据：name、description 等，供系统识别与检索。
  • 用途与触发条件：说明什么场景该启用该 Skill（避免乱用）。
  • 输入/输出规范：明确要吃什么、吐什么、按什么结构吐。
  • 工作流（Workflow）：把任务拆成有序步骤，指导智能体怎么做。
  • 质量底线：必须满足的硬约束（如"六大模块缺一不可""链接真实不编造"），保证一致性。

运行机制要点

  • 按需加载：智能体识别到任务匹配某 Skill 触发条件，才把它的说明注入上下文，而非全程挂着所有 Skill（省 token、防干扰）。
  • 指令驱动：Skill 本质是结构化提示词 + 可选工具，靠 LLM 按指令执行；模型越强，Skill 表现越好。
  • 可积累复用：一次写好，多次/多人复用，把"经验"固化成可分发的资产——这正是它与一次性提示词的根本区别。

学术上，"把习得能力存进技能库供后续复用"的思路在 Voyager（Minecraft 智能体）等工作里有清晰体现：智能体把成功的程序代码存为"技能"，遇到新任务时检索复用，从而持续成长。

3真实应用场景

场景用在什么产品/环节为什么用 Skill角色
智能体平台WorkBuddy：用 SKILL.md 定义能力（如本页的 concept-learning-generator）把可复用任务封装成稳定能力，无需重写提示词核心方法
定制助手OpenAI Custom GPTs：把指令+工具+知识打包成一个 GPT用户一键获得某领域专长，跨对话复用核心方法
智能体成长Voyager：把成功代码存为技能，遇到新任务检索复用让智能体积累能力而非每次从零开始核心方法
工具编排LangChain/LangGraph：把工具+提示封装成可复用 Agent 能力标准化"工具+流程"组合，便于组合调用辅助组件
企业流程把"发周报""跑某分析"等固定流程写成 Skill 供团队调用把团队最佳实践固化，人人得到一致产出核心方法

共性：Skill 把"怎么做某件事"的知识从人脑/零散提示词里抽出来，固化为可加载、可复用、可迭代的资产。

4易混淆边界

易混概念与本概念（Skill）的关键差异何时用哪个
工具 (Tool)工具是"单个可调用函数"（如一个 API）；Skill 是"说明书+工具+流程"的整体打包执行原子动作用工具；完成一类完整任务用 Skill
提示词模板 (Prompt Template)模板只是"填空式文本"；Skill 含触发条件、工作流、质量底线，是结构化能力一次性套格式用模板；要稳定可复用能力用 Skill
微调 (Fine-tuning)微调改模型权重（永久改变行为，需训练）；Skill 不改权重，运行时注入上下文要改变模型内在能力用微调；要编排任务流程用 Skill
插件 (Plugin)插件侧重"连接外部服务/API"；Skill 侧重"教智能体怎么做某类任务"（可不含外部连接）要接外部系统用插件；要传授做事方法用 Skill

6自测思考题

  1. 复述：Skill 和"写一段好用的提示词"有什么本质不同？为什么说前者是"资产"而后者不是？
    提示方向：从触发条件、工作流、质量底线、可复用四点切入。
  2. 机制题：Skill 加载后，模型是"学会了新技能"还是"只是按注入的说明做事"？结合微调与上下文的关系说明。
    提示方向：权重是否变化、能力是否运行时注入。
  3. 辨析题：你写了一个"调用某 API 查库存"的函数。它算 Skill 还是 Tool？要升级成 Skill 还缺什么？
    提示方向：单函数 vs 说明书+流程+质量底线。
  4. 应用题：团队里每个人都各自写提示词做周报，结果格式各异。如何用 Skill 统一产出？列出你的 Skill 至少要含哪些部分。
    提示方向：元数据、触发、工作流、质量底线。
  5. 迁移题：参照 Voyager 的"技能库"思路，一个智能体如何在反复执行任务中越来越强？Skill 在其中扮演什么角色？
    提示方向：存成功经验→检索复用→持续成长。
