# Agent（智能体）

> 生成日期：2026-09-09 ｜ 类别：AI 概念学习资料

（注：本文讲 "Agent" 作为 AI 系统形态的概念——以大模型为大脑、能自主规划与行动完成任务。库内 [agent-skill.md](agent-skill.md) 讲的是智能体用的"技能包"机制，两文互为补充：那篇讲智能体的装备，这篇讲智能体本身。）

## 1. 概念个人解释

先打个比方：聊天机器人像一台答题机——你问一句它答一句，答完就停，绝不主动多走一步。智能体像一位被分配任务的员工——你给一个目标（"把这份报告排好版"），它会自己拆步骤、查资料、调工具、执行、发现不对再改，循环往复直到任务完成。"会不会自己往前走"，是它与答题机的分水岭。

正式一点说：Agent（智能体）是以大语言模型为推理核心、能自主感知—规划—行动来完成端到端任务的 AI 系统。它区别于单轮问答的关键特征是"行动闭环"：感知（理解任务与输入）→ 规划（拆解步骤）→ 行动（调用工具、执行代码、操作环境）→ 观察（读取结果）→ 调整，循环直至目标达成或主动停止。本仓库正在用的 concept-material-generator 触发时，就经历了一次微型智能体循环：读 SKILL.md → 查重 → 撰写 → 核验 → 自检 → 落盘 → 汇报。

## 2. 核心机制或组成

一个智能体的行动闭环（agentic loop）由五部分组成：

1. **大模型（大脑）**：负责推理、规划与决策——把"完成 X 任务"翻译成一系列具体行动。模型能力是智能体的能力上限。
2. **工具（手脚）**：函数调用、API、代码执行器、浏览器、文件读写等——把模型的"想"变成对外部世界的"做"。
3. **记忆（背景）**：短期记忆是对话上下文（窗口有限，见 [llm-context.md](llm-context.md)）；长期记忆靠外部存储/检索按需注入——跨会话延续。
4. **规划循环（引擎）**：把"目标"展开为"步骤序列"的核心范式——ReAct（推理+行动交替）、Plan-and-Execute（先规划再执行）、反思（self-reflection，做完自检再继续）。
5. **环境（工作台）**：智能体操作的世界——终端、浏览器、代码库、文件系统、应用界面。环境的反馈是下一轮行动的输入。

可选但常见配套：技能（skills，按需加载的方法包，详见 [agent-skill.md](agent-skill.md)）、MCP（连接外部系统的协议）。它们扩展智能体的"手能伸到的地方"。

## 3. 具体应用场景

1. **编程智能体**：Claude Code、Cursor、Codex 等读代码库、写代码、跑测试、修 bug——把"开发"变成一条"目标→闭环执行"的指令，是 2025 年最成熟的智能体落地形态。
2. **通用任务智能体**：Claude（带工具/Artifacts/Skills）、ChatGPT（带工具/代码解释器）完成多步任务——数据分析、文档制作、调研，一次对话产出一个交付物而非一个回答。
3. **浏览器/网页自动化智能体**：自动填表、采集、跨页面操作——代替人在多个网页间点击穿行的重复劳动。
4. **企业垂直工作流智能体**：数据处理管线、报告生成、客服坐席等——在确定域内承担端到端流程，常与 workflow 编排结合使用。

## 4. 容易混淆的问题或使用边界

1. **Agent vs Chatbot（聊天机器人）**：单轮问答 vs 多步行动闭环。chatbot 是"答"，agent 是"做"——前者优化"说得对"，后者优化"做成了"。一个标志：chatbot 没有工具就没有行动力，agent 没有工具就退化成 chatbot。
2. **Agent vs Workflow（工作流）**：workflow 是预定义的固定流程图（deterministic，每步分支预先写死）；agent 是动态规划（每步下一步由模型当期决定）。Anthropic 的经典划分：确定性高、容错低的任务用 workflow，开放性强、需要自主判断的任务用 agent。两者常组合——用 workflow 兜底确定性部分，用 agent 处理需要变通的部分。
3. **Agent vs Assistant（助手）**：assistant 侧重对话交互的陪伴感；agent 侧重端到端把事做完的责任感。差别在"对结果负责"的程度：助手陪你聊，替你做。
4. **使用边界与失效条件**：自主性的代价是会绕路、会犯错——关键场景必须加护栏（权限限制、人在环确认、沙箱隔离）；任务过于确定时硬套 agent 是过度设计，纯 workflow 更省更稳；模型推理能力不足时，再多工具也撑不起 agent——智能体的下限由模型决定，上限由工具与编排决定。
