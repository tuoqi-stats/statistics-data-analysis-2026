# concept-material-generator（概念学习资料生成器）

> 生成日期：2026-09-09 ｜ 类别：AI 概念学习资料

（注：本文的介绍对象不是通用 AI 概念，而是本仓库中的一个具体 Agent Skill 实例——也就是 agent-skill.md 一文中"活例子"的主角。你现在读的这份文档，正是由它自己生成的。）

## 1. 概念个人解释

先打个比方：它像一位按固定格式整理笔记的私人学习助理。你对它说"帮我整理 X 概念"，他不自由发挥，而是掏出一张固定的五栏表格——大白话解释、机制拆解、应用场景、易混淆边界、权威链接——逐栏填完，存档、登记索引，然后向你汇报每栏要点。

正式一点说：concept-material-generator（用户也常称它 concept-learning-generator）是本仓库的项目级 Agent Skill，源文件位于 `.workbuddy/skills/concept-material-generator/SKILL.md`。它接收任意 AI / 机器学习 / 统计学习概念名词，按固定的五段式模板生成标准化学习文档，保存到仓库根目录 `learning-materials/` 目录。它把"学一个新概念"从"漫无目的地搜资料"变成"一句指令产出结构化笔记"。

有一点趣味值得点出：这份文档本身就是它的产出——这个 skill 正在介绍它自己，相当于让笔记助理给自己记一份档案。

## 2. 核心机制或组成

这个 skill 的设计可以拆成五个关键要素：

1. **单文件设计**：整个 skill 只有一个约 84 行的 SKILL.md（无 scripts/、references/、assets/ 资源包），内容分六章：适用场景、输入信息、生成步骤、输出结构、资料来源要求、自检要求——对一个纯"内容生成"类 skill，单文件即够用，是极简主义的范例。
2. **五段式输出模板**（固定标题，一字不差）：
   1. 概念个人解释（先类比后定义）
   2. 核心机制或组成（至少拆解 2 个要素）
   3. 具体应用场景（至少 3 个带实例的场景）
   4. 容易混淆的问题或使用边界（至少 1 组 "X vs Y" 对照）
   5. 可核查资料来源链接（2-5 条，逐条附价值说明）
3. **七步生成流程**：确认概念（一词多义先消歧）→ 查重（防止误覆盖已有文档）→ 按模板撰写 → 落实并核验链接 → 自检清单逐项核对 → 保存（文件名小写 kebab-case）→ 向用户汇报路径与各部分要点。
4. **质量约束条款**（这个 skill 的"性格"）：
   - 链接宁缺毋假：必须本会话核验可达（curl 状态码 200）或高度确信的权威页面，否则改写为"建议检索关键词"，禁止输出虚构 URL
   - 不使用需要登录或付费的链接
   - 写入文件前必须通过全部自检项
5. **配套索引约定**：`learning-materials/README.md` 作为目录索引，每次生成后登记新文档，形成可检索的概念知识库。

## 3. 具体应用场景

1. **日常概念学习**：在 WorkBuddy 对话中说"用 concept-material-generator 生成 <概念名> 的学习资料"即触发——本会话就连续生成了三份：Agent Skill（agent-skill.md）、大模型上下文（llm-context.md），以及本文。
2. **统计学习课程配套**：本仓库是"统计与数据分析"课程仓库，可随时为课程概念（如假设检验、贝叶斯推断、Bootstrap、方差分析）生成统一格式的复习资料，随学随补。
3. **团队知识沉淀**：skill 位于项目级目录（`.workbuddy/skills/`），随仓库共享——同一门课的同学获得的是同一个标准、同一套流程生成的笔记，而不是各自风格的手写笔记；新概念学完即沉淀，可复习、可对比、可交接。

## 4. 容易混淆的问题或使用边界

1. **这个 skill vs 手动记笔记**：核心价值在"固定结构 + 质量约束"——每份文档结构一致（便于复习与横向对比），链接全部核验（不混入编造来源）；手动笔记结构随意、来源质量参差。
2. **这个 skill vs 直接向 AI 提问**：直接问"解释一下 X"得到的是一次性、无结构、随答随弃的回答；本 skill 强制落盘到 `learning-materials/` 并登记索引，答案变成资产而非消耗品。
3. **这个 skill vs WorkBuddy 内置办公 skill（如 tencent-docx、tencent-pptx）**：内置办公 skill 解决"文件格式"（生成 docx/pptx/xlsx）；本 skill 解决"学习内容"本身，输出纯 Markdown——两者可串联（生成本文档后再转 docx）。
4. **使用边界与失效条件**：只生成五段式学习文档，不承担其他任务（不做练习题、不做对比工具、不生成演示文稿）；输入须是"可学习的概念名词"而非任务指令；资料来源受本机网络可达性约束——例如本机无法访问 Wikipedia（2026-09-09 实测），相关权威词条会被替换为可达来源或改写为检索关键词。
