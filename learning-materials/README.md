# learning-materials — AI 概念学习资料库

本目录存放由项目 skill `concept-material-generator`（位于 `.workbuddy/skills/concept-material-generator/`）生成的概念学习文档。

## 约定

- 每个概念一份文档，固定五部分结构：概念个人解释 / 核心机制或组成 / 具体应用场景 / 容易混淆的问题或使用边界 / 可核查资料来源链接
- 文件名使用小写 kebab-case：优先概念通用英文或缩写（如 `rag.md`、`transformer.md`），无通用英文时用拼音
- 生成方式：在 WorkBuddy 对话中直接说"用 concept-material-generator 生成 <概念名> 的学习资料"
