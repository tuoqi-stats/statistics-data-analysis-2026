Agent（智能体）

1个人通俗解释

Agent就像一个有授权的实习生。 普通大模型是军师：你问它才答，只出主意，不干活。 Agent接到目标后会自主干活：拆分任务、查资料、写代码、自我校验，失败就换方案，直到完成任务。 普通AI靠人一步步驱动；Agent自己做决策推进。 Agent的内核还是大模型，只是额外加上观察、调用工具、自我复盘的能力，从“会说”变成“会做”。

2核心机制

Agent 的运行遵循一个经典循环：感知 → 推理/规划 → 行动 → 观察（Perception → Reasoning/Planning → Action → Observation），不断迭代直到目标达成。学术界把这个模式称为 ReAct（Reason + Act）。

思考循环：
Thought (思考下一步该做什么)
Action (调用某个工具/函数)
Observation (读取工具返回的结果)
→ 回到 Thought … 直到得到最终答案 // 循环直至完成

关键组成部件

  • 规划（Planning）：把大目标拆成可执行的子任务，常用"思维链（Chain-of-Thought）"或任务分解（如把"做报表"拆成"取数→清洗→汇总→可视化→写结论"）。
  • 记忆（Memory）：短期记忆即当前对话/上下文；长期记忆通常借助向量数据库存储历史经验，按需检索复用。
  • 工具使用（Tool Use）：通过"函数调用（function calling）"执行外部动作，如搜索网页、运行代码、读写文件、调 API。
  • 行动执行（Action）：真正"动手"的部分——工具调用后，Agent 观察返回结果并决定下一步。

机制要点

LLM 在这里扮演决策中枢：它不直接"知道"外部世界的状态，而是通过工具调用的输入/输出来间接感知和影响世界。循环的每一步都靠 LLM 推理决定，因此 Agent 的能力上限高度依赖底座模型的质量、工具集的丰富度，以及规划策略的好坏。

3真实应用场景

场景用在什么产品/环节为什么用 Agent角色
编程开发Cursor、Claude Code、GitHub Copilot Workspace：读懂代码库、改多文件、跑测试、提 PR修一个 bug 涉及"定位→改代码→验证"，单轮对话做不完，需要自主多步执行核心方法
深度研究OpenAI Deep Research、Perplexity Pro：多轮检索、阅读、综合成报告研究报告需反复搜索+阅读+提炼，Agent 能自主迭代搜索策略核心方法
客服运营电商自动客服：查订单、改地址、发起退款、通知物流处理流程要查数据库+调业务系统，不是单纯聊天能完成核心方法
数据分析ChatBI 类 Agent：自然语言提问→写 SQL→出图→解读分析是"取数→可视化→总结"的多步任务，适合 Agent 自主编排核心方法
浏览器自动化网页抓取/填表/比价 Agent：模拟人操作网页网站操作步骤多变、需判断页面状态，硬编码脚本难覆盖核心方法

共同点：这些场景都需要"看情况决定下一步"，而非固定流程——这正是 Agent 相对普通脚本/聊天机器人的价值所在。

4易混淆边界

易混概念与本概念（Agent）的关键差异何时用哪个
聊天机器人 (Chatbot)聊天机器人只做"问答"，一轮结束；Agent 会自主多步行动、使用工具、改变外部状态只需回答问题用 Chatbot；要完成需多步+工具的任务用 Agent
工作流 (Workflow)工作流是预先编排好的固定流程图；Agent 是运行时动态决策下一步做什么步骤确定、可预测用 Workflow；步骤依赖中间结果、需灵活判断用 Agent
Copilot / 助手Copilot 侧重"辅助人"，每步多由人确认；Agent 更强调"自主完成"，人只给目标要人时刻参与/审核用 Copilot；希望系统自主跑通全程用 Agent
RPA 机器人RPA 按固定脚本录制回放操作；Agent 靠 LLM 理解意图并临场决策流程稳定不变用 RPA；流程多变、需理解语义用 Agent

6自测思考题

  1. 用一句话向一个不懂技术的朋友解释 Agent 和聊天机器人的区别。
    提示方向：从"是否会主动多步行动"切入。
  2. 在 ReAct 循环里，如果某个工具调用返回了错误结果，Agent 接下来会做什么？为什么这个能力对它很重要？
    提示方向：观察→思考→调整下一步。
  3. 请判断："按固定脚本自动登录并抓取数据的程序"算不算 Agent？说明理由，并指出它更接近哪类系统。
    提示方向：对照 Workflow/RPA 与 Agent 的边界。
  4. 假设要做一个"每天自动追踪竞品价格并生成周报"的系统，你会用 Workflow 还是 Agent？哪些环节适合交给 Agent 决策？
    提示方向：区分"固定步骤"与"需临场判断"的部分。
  5. Agent 的能力受哪三个因素制约？如果底座模型不变，最可能提升 Agent 表现的是改进哪一块？
    提示方向：模型 + 工具集 + 规划/记忆策略。
